STREAM CLIPPER — АВТОПУБЛИКАЦИЯ: что настроить один раз

Автопилот публикует только через официальные API площадок: так безопасно, за это не банят.
Каждую площадку нужно один раз подключить в окне программы: «Настройки» → «📤 Автопубликация».
Ключи хранятся только на твоём компьютере.

──────────────── YOUTUBE ────────────────
1. Открой https://console.cloud.google.com/ и войди тем Google-аккаунтом, на котором канал.
2. Создай проект (любое имя, например «Stream Clipper»).
3. «APIs & Services» → «Library» → найди «YouTube Data API v3» → «Enable».
4. «APIs & Services» → «OAuth consent screen»: тип «External». Впиши имя приложения и свою почту.
   В «Test users» добавь свою же почту.
5. «APIs & Services» → «Credentials» → «Create credentials» → «OAuth client ID» → тип «Desktop app».
   Нажми «Download JSON»: это и есть client_secret.json.
6. В Stream Clipper нажми «Подключить (файл client_secret.json)…», выбери файл и войди в браузере.
   Google покажет «приложение не проверено». Это твоё же приложение: нажми «Дополнительно» → «Перейти».
ВАЖНО: пока Google не проверил приложение (заявка в «OAuth consent screen» → «Publish app», проверка занимает недели),
видео, загруженные через API, YouTube делает ПРИВАТНЫМИ. Программа это покажет. Такие видео можно открыть
в YouTube Studio и сделать «Открытыми» одним кликом.

──────────────── INSTAGRAM ────────────────
Нужен аккаунт Instagram Business или Creator (в приложении Instagram: Настройки → Тип аккаунта).
1. Открой https://developers.facebook.com/ → «My Apps» → «Create App» → тип «Business».
2. Добавь продукт «Instagram» → «API setup with Instagram login».
3. Добавь свой аккаунт Instagram и нажми «Generate token». Разрешения: instagram_business_basic,
   instagram_business_content_publish.
4. Скопируй токен и ID аккаунта Instagram, вставь их в Stream Clipper → «Подключить».
   Если токен «короткий» (на 1 час), там же обменяй его на долгосрочный (на 60 дней).
   Раз в два месяца токен нужно обновлять.

──────────────── TIKTOK ────────────────
1. Открой https://developers.tiktok.com/ → «Manage apps» → «Connect an app».
2. Добавь продукты «Login Kit» и «Content Posting API».
3. В Login Kit укажи адрес возврата (Redirect URI) ровно такой: http://localhost:8723/callback/
4. Разрешения (scopes): user.info.basic, video.upload.
5. Скопируй Client key и Client secret в Stream Clipper → «Подключить», войди в браузере.
ВАЖНО: пока TikTok не проверил приложение, видео приходят в ЧЕРНОВИКИ TikTok. В телефоне придёт уведомление,
останется открыть черновик и нажать «Опубликовать». Описание с хэштегами программа пришлёт в Telegram
(если он подключён), чтобы его можно было вставить. Кликать «Опубликовать» в браузере за тебя программа
не будет: за такую автоматизацию TikTok банит аккаунты.

──────────────── АВТОПИЛОТ ────────────────
Вкладка «Управление» → блок «Что происходит»: переключатели «🤖 Автопилот» и «⏸ Пауза публикаций».
Автопилот сам отбирает клипы, проверяет их на риски, монтирует под каждую площадку и публикует в окна из
стратегии «Доктора шортсов». Для просмотра кадров ему нужен ключ Claude («Настройки» → «Ключ Claude API»).
Негодные клипы он уносит в «Архив», а не удаляет. Журнал решений: лента «Что происходит» и файл exchange/autopilot_log.json.
