# «Мой день»: как запустить сайт

Сайт лежит в папке `docs/`. Это одна страница без сервера: записи хранятся на телефоне,
а соревнование и резервная копия идут через бесплатную базу Firebase Firestore.

## 1. Включить GitHub Pages

1. Репозиторий должен быть **открытым** (бесплатный GitHub Pages работает только для открытых).
   Settings → General → Danger Zone → Change visibility → Public.
   В репозитории нет личных данных: записи хранятся на телефонах и в вашей базе Firebase.
2. Settings → Pages → Build and deployment → Source: **Deploy from a branch**.
3. Branch: `claude/self-tracker` (или `main`, если ветка влита), папка **/docs** → Save.
4. Через 1–2 минуты сайт откроется по адресу `https://miiranov21.github.io/miiranov/`.

## 2. Подключить облако для соревнования (Firebase)

1. Зайди на https://console.firebase.google.com с аккаунтом Google → «Создать проект».
   Название любое, например `moy-den`. Google Analytics можно отключить.
2. В меню слева: Build → **Firestore Database** → Create database.
   Расположение: `eur3 (europe-west)`. Режим: **production**.
3. Вкладка **Rules** → удали всё и вставь содержимое файла `docs/firestore.rules` → Publish.
4. Шестерёнка → Project settings → скопируй **Project ID** (например `moy-den-1a2b3`).
5. Впиши его в `docs/config.js` в строку `projectId: ""` и сохрани (или пришли Project ID Claude).

Платёжная карта не нужна: бесплатного тарифа Spark хватает с большим запасом.

## 3. Пара

1. Открой сайт, впиши своё имя в блоке «Битва» и нажми **«Создать пару»**.
2. Отправь девушке код из 12 символов.
3. Она открывает сайт → «Подключиться» → вводит код → «Я новый участник».
4. На новом телефоне вводишь тот же код и выбираешь себя: записи загрузятся из облака.

Код пары — это ключ. Не публикуй его: кто знает код, видит итоги дня и может записать в вашу пару.

## 4. На экран iPhone

Safari → открыть сайт → «Поделиться» → **«На экран „Домой“»** → «Добавить».
Сайт откроется на весь экран со своей иконкой и работает без интернета.
